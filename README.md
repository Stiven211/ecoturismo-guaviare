# Ecoturismo Guaviare

Sitio de promoción de destinos y experiencias de ecoturismo en el Guaviare, con
enfoque visual en naturaleza y aventura.

**Demo:** https://ecoturismo-inky.vercel.app

## Stack

HTML, CSS y JavaScript sin build ni dependencias.

## Local

Abre `index.html` en el navegador o sirve la carpeta:

```bash
python -m http.server 8080
```
